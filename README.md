# 골프 레슨 영어

클럽별로 레슨에서 자주 생기는 **상황**을 골라, 그 상황에서 쓰는 영어 문장을 **한국어 버튼을 눌러 영어 음성으로 듣고** 연습하는 웹앱이에요.
날짜 제한 없이 아무 때나 원하는 클럽과 상황부터 공부할 수 있어요.
빌드 도구 없이 HTML, CSS, JS만으로 만들어서 GitHub에 올리고 Vercel에 연결하면 바로 열려요.

## 문장 구성 (모두 80개)

드라이버, 우드, 아이언, 웨지, 퍼터마다 16문장이에요. 스윙 순서대로 네 단계로 나눴어요. (퍼터는 백스트로크, 포워드 스트로크로 표시돼요)

| 단계 | 상황 수 | 어떤 상황인가요 |
| --- | --- | --- |
| 스탠스 | 5 | 조금 더 넓게, 조금 좁게, 공을 앞으로, 타깃보다 오른쪽/왼쪽을 보고 설 때 |
| 백스윙 | 4 | 너무 빠를 때, 몸이 밀릴 때, 오버스윙, 어깨가 안 돌 때처럼 자주 문제 되는 부분 |
| 다운스윙 | 4 | 위에서 덮어 칠 때, 손목이 일찍 풀릴 때, 체중이 뒤에 남을 때 등 |
| 피니시 | 3 | 임팩트에서 멈출 때, 뒤로 넘어질 때, 균형이 흔들릴 때 등 |

## 화면

| 화면 | 하는 일 |
| --- | --- |
| 클럽별 (첫 화면) | 클럽을 고르고, 단계를 고르면 상황별 문장이 나와요. 한국어 문장을 누르면 영어로 읽어 줘요. 익힌 문장은 `익혔어요`로 표시해 두면 클럽별로 몇 개 익혔는지 보여 줘요. |
| 연습 | 따라 말하기(마이크로 점수), 빈칸 채우기, 쓰기. 클럽과 스윙 단계를 골라서 그 범위 안에서만 연습할 수 있어요. |
| 오늘 | 80일 동안 하루 한 문장. 80문장이 한 번씩 나와요. 날짜와 상관없이 아무 날이나 눌러서 열 수 있어요. 오늘 날짜는 참고용일 뿐 잠겨 있는 날은 없어요. |
| 소리 | 영어 목소리, 속도, 높낮이 조절. 오늘의 한 문장 시작일 변경. |

- 오늘의 한 문장 순서는 `sentences.js`의 `PLAN_SEED` 값으로 정해져요. 같은 값이면 두 사람의 폰에서 **같은 날 같은 문장**이 나와요.
- 시작일은 처음 연 날이 1일차예요. 함께 공부하는 사람과 시작일을 맞추려면 `소리` 화면에서 같은 날짜로 바꿔 주세요.
- 학습 기록(익힘, 완료 표시, 점수)은 각자의 기기와 브라우저에만 저장돼요. 서로 공유되지는 않아요.

## 영어 목소리에 대해

목소리는 **기기에 설치된 음성**(브라우저의 Web Speech API)으로 재생돼요. 앱이 미국 남성 목소리를 자동으로 먼저 골라요.

- Windows의 Edge와 Chrome: Microsoft Davis, Andrew, Guy 같은 Natural 음성이 가장 자연스러워요.
- 아이폰과 맥의 Safari: Evan, Aaron, Alex 같은 남성 음성. 설정 > 손쉬운 사용 > 읽어주기 > 음성에서 고품질 버전을 내려받으면 더 좋아져요.
- 안드로이드: 기기마다 달라서 `소리` 화면에서 직접 골라 보세요.

기기마다 목소리가 조금씩 달라요. **누가 열어도 똑같은 목소리**가 필요하면 녹음 파일을 쓰면 돼요.

1. 문장별 mp3를 `audio/<문장 id>.mp3`로 저장해요. 예: `audio/driver-backswing-2.mp3` (id는 `<클럽>-<단계>-<번호>` 형식이고, 단계는 `stance`, `backswing`, `downswing`, `finish`예요)
2. `sentences.js`에서 `USE_RECORDED_AUDIO: true`로 바꿔요.

파일이 없는 문장은 자동으로 기기 음성으로 읽어요. 음성 합성 서비스(ElevenLabs, OpenAI 등)로 80개를 한 번만 만들어 넣어도 돼요.

## 내 컴퓨터에서 열어보기

폴더에서 간단한 웹서버를 켜요. (마이크 인식은 `https` 또는 `localhost`에서만 동작해서, 파일을 더블클릭해 여는 방식은 권장하지 않아요.)

```bash
python3 -m http.server 8000
# 또는
npx serve
```

브라우저에서 `http://localhost:8000`을 열어요.

## Vercel로 배포하기

1. [vercel.com](https://vercel.com)에 GitHub 계정으로 로그인해요.
2. `Add New` > `Project`에서 `golfzone` 저장소를 `Import`해요. (저장소가 private이면 Vercel에 접근 권한을 줘야 목록에 보여요)
3. 설정은 그대로 두면 돼요. Framework Preset은 `Other`, Build Command와 Output Directory는 비워 둬요.
4. `Deploy`를 누르면 `https://golfzone-xxxx.vercel.app` 주소가 생겨요.

이후에는 `main`에 push할 때마다 자동으로 다시 배포돼요.

## 한 사람과 공유하기

- 가장 간단한 방법: 배포된 `vercel.app` 주소를 그 사람에게 보내요. 폰 브라우저에서 열고 `홈 화면에 추가`를 해 두면 앱처럼 쓸 수 있어요.
- 주소를 열었을 때 Vercel 로그인 화면이 뜨면 프로젝트의 `Settings` > `Deployment Protection`에서 보호 범위를 확인해 주세요.
- 문장을 같이 고치고 싶다면 GitHub 저장소 `Settings` > `Collaborators`에서 상대를 초대해요. 다만 Vercel 무료(Hobby) 플랜은 팀 협업이 제한돼서, 한 사람이 push를 맡는 방식이 가장 단순해요.

## 문장 바꾸기

`sentences.js`만 고치면 돼요. 한 줄이 한 상황이에요.

```js
['백스윙이 너무 빠를 때',                                   // 상황
  'Slow down your backswing, and let the club move back smoothly.',   // 영어
  '백스윙 속도를 줄이고 클럽이 부드럽게 올라가게 하세요.',          // 한국어
  'smoothly', 'adv', '부드럽게']                              // 빈칸 단어, 품사, 뜻
```

- 빈칸 단어는 영어 문장 안에 그대로 들어 있어야 해요. (빈칸 채우기 연습에 써요)
- 품사는 `n`(명사), `v`(동사), `adj`(형용사), `adv`(부사) 중 하나예요.
- 단계마다 줄을 더하거나 빼도 돼요. 오늘의 한 문장은 80일이 기본이라, 문장이 80개보다 많으면 일부만 나오고 적으면 처음부터 다시 돌아요.
